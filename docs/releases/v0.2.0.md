# WinMdConverter v0.2.0

此版本新增 Markdown 轉 DOCX，並改善 Microsoft Edge Headless 產生 PDF 的相容性與診斷資訊。

## 下載選擇

- `WinMdConverter-Setup-0.2.0-x64.exe`：建議一般使用者下載，可建立開始功能表與桌面捷徑，並可選擇將 CLI 加入 PATH。
- `WinMdConverter-0.2.0-win-x64.zip`：免安裝可攜版，解壓縮後執行 `WinMdConverter.exe`。
- `SHA256SUMS.txt`：安裝檔與可攜版的 SHA-256 摘要。

## 新增功能

- GUI 與 CLI 支援輸出 DOCX。
- DOCX 支援標題、段落、清單、表格、程式碼、連結及本機圖片。
- DOCX 支援靜態可點擊目錄、Windows 字型、A4 方向及頁面邊界。
- HTML、PDF、DOCX 可任意組合輸出。
- CLI `--format` 支援逗號組合及 `all`。

## PDF 改善

- Edge `--headless=new` 失敗時自動改用相容模式重試。
- 每次嘗試使用獨立的暫存 Edge Profile。
- 等待 PDF 完成寫入後才判定結果。
- 失敗時顯示 Edge Exit Code 與兩次嘗試的診斷資訊。

## 介面改善

- 提高主介面次要文字與停用按鈕的色彩對比。
- 主介面頁尾顯示目前 WinMdConverter 軟體版本。

## CLI 變更

`--format` 現在為必填，且不再支援 `both`。請改用明確的逗號組合：

```powershell
mdconvert document.md --format html,pdf
mdconvert document.md --format docx
mdconvert document.md --format all
```

`--help`、`--version` 與 `--list-fonts` 不需要指定 `--format`。

## 注意事項

- PDF 輸出需要系統 Microsoft Edge。
- DOCX 不需要安裝 Microsoft Word。
- DOCX 不下載遠端圖片，也不支援 WebP 圖片；遇到這些圖片時會顯示警告並繼續轉換。
- 縮放比例只套用於 HTML 與 PDF。
- 此版本尚未進行程式碼簽章，Windows SmartScreen 可能在第一次執行 Setup EXE 時顯示提醒。

完整操作方式請參閱[使用指南](../使用指南.md)與 [CLI 參考](../CLI參考.md)。
