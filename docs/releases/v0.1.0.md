# WinMdConverter v0.1.0

WinMdConverter 的第一個公開版本，提供繁體中文 Windows 圖形介面與 `mdconvert` CLI，可在本機將 Markdown 轉換成 HTML、PDF 或同時輸出兩種格式。

## 下載選擇

- `WinMdConverter-Setup-0.1.0-x64.exe`：建議一般使用者下載，可建立開始功能表與桌面捷徑，並可選擇將 CLI 加入 PATH。
- `WinMdConverter-0.1.0-win-x64.zip`：免安裝可攜版，解壓縮後執行 `WinMdConverter.exe`。
- `SHA256SUMS.txt`：安裝檔與可攜版的 SHA-256 摘要。

## 主要功能

- Markdig Advanced Extensions。
- HTML、PDF 或同時輸出。
- A4 直向與橫向。
- 符合頁面與 50%～200% 自訂縮放。
- 預設、無、最小及四邊自訂邊界。
- 文件開頭目錄與可點擊錨點。
- Windows 已安裝字型及中文字型別名。
- 本機圖片內嵌。
- 轉換進度、取消及完成連結。
- CLI JSON 輸出與明確 Exit Code。

## 系統需求

- Windows 10 或 Windows 11 x64。
- 已內附 .NET 8 Runtime，不需要另外安裝 .NET。
- PDF 輸出需要系統 Microsoft Edge。

## 注意事項

此版本尚未進行程式碼簽章，Windows SmartScreen 可能在第一次執行 Setup EXE 時顯示提醒。請確認檔案由本 GitHub Release 下載，並使用 `SHA256SUMS.txt` 核對檔案摘要。

完整操作方式請參閱[使用指南](../使用指南.md)與 [CLI 參考](../CLI參考.md)。
