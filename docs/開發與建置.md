# 開發與建置

## 技術架構

| 專案 | 用途 |
|---|---|
| `WinMdConverter.Core` | Markdown、HTML、圖片、字型、驗證與 Edge PDF 轉換 |
| `WinMdConverter.App` | WPF 圖形介面 |
| `WinMdConverter.Cli` | `mdconvert` 命令列工具 |
| `WinMdConverter.Tests` | xUnit 核心與 CLI 測試 |

主要技術：

- C# / .NET 8
- WPF
- Markdig 0.41.3
- Microsoft Edge Headless
- xUnit
- Inno Setup 6

## 轉換流程

```text
Markdown
  -> Markdig UseAdvancedExtensions
  -> 標題錨點與目錄
  -> 本機圖片內嵌
  -> HTML5 與列印 CSS
  -> HTML 檔案
  -> Microsoft Edge Headless
  -> PDF 檔案
```

GUI 與 CLI 都呼叫 `MarkdownConversionService`，避免兩種入口產生不同結果。

## 開發環境

必要環境：

- Windows 10/11 x64
- .NET 8 SDK 或可建置 `net8.0-windows` 的更新 SDK
- Microsoft Edge，用於 PDF 整合測試
- PowerShell 7，用於發佈腳本
- Inno Setup 6，用於產生安裝檔

確認 SDK：

```powershell
dotnet --info
```

## 還原與建置

```powershell
dotnet restore WinMdConverter.sln
dotnet build WinMdConverter.sln
```

專案啟用 Nullable、Implicit Usings、Deterministic Build，並將編譯警告視為錯誤。

## 執行

GUI：

```powershell
dotnet run --project src/WinMdConverter.App
```

CLI：

```powershell
dotnet run --project src/WinMdConverter.Cli -- --help
```

## 測試

```powershell
dotnet test WinMdConverter.sln
```

測試涵蓋：

- Advanced Markdown 與表格
- 目錄及重複標題錨點
- 停用 Raw HTML
- 本機圖片內嵌
- 縮放與邊界驗證
- HTML 實際寫入
- Windows 中文字型別名
- CLI 完整參數及錯誤參數

涉及 PDF 的真實煙霧測試需要 Microsoft Edge，目前由 Release 驗證流程手動執行。

## 圖示

圖示來源位於 `assets/WinMdConverter.svg`，Windows 多尺寸圖示可重新產生：

```powershell
pwsh -File scripts/Generate-Icon.ps1
```

腳本會建立：

- `assets/WinMdConverter.ico`
- `assets/WinMdConverter.png`

ICO 包含 16、20、24、32、40、48、64、128 及 256 px 影格。

## Windows 發佈

完整發佈：

```powershell
pwsh -File scripts/Publish.ps1
```

腳本依序：

1. 重新產生圖示。
2. 執行 Release 測試。
3. 發佈 GUI 與 CLI 的 `win-x64` self-contained 版本。
4. 合併共用 .NET Runtime，避免重複檔案。
5. 只保留繁體中文 satellite resources。
6. 建立 Portable ZIP。
7. 下載官方 Inno Setup 繁體中文語言檔。
8. 產生繁體中文 Setup EXE。
9. 清除建置用語言檔及暫存目錄。

輸出位於：

```text
artifacts/
├─ portable/
├─ WinMdConverter-0.1.0-win-x64.zip
├─ WinMdConverter-Setup-0.1.0-x64.exe
└─ SHA256SUMS.txt
```

只建立可攜版：

```powershell
pwsh -File scripts/Publish.ps1 -SkipInstaller
```

略過測試：

```powershell
pwsh -File scripts/Publish.ps1 -SkipTests
```

正式發佈不建議略過測試。

## 版本更新

發佈新版本時需同步：

1. 更新 `Directory.Build.props` 的版本。
2. 更新 `CHANGELOG.md`。
3. 以 `scripts/Publish.ps1 -Version x.y.z` 產生檔案。
4. 建立 `vx.y.z` Git Tag 與 GitHub Release。
5. 上傳 Setup EXE 與 Portable ZIP。

## 安全注意事項

- Raw HTML 預設停用，不應在未審查前開啟。
- 呼叫 Edge 時使用獨立暫存 Profile，完成後清除。
- 寫入 HTML 與 PDF 時先使用暫存檔，成功後再替換正式檔。
- 不得在 repository、設定檔或 Release 腳本中提交憑證與 Token。
