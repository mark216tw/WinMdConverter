# WinMdConverter 使用指南

## 安裝方式

### Windows 安裝版

1. 從 [GitHub Releases](https://github.com/mark216tw/WinMdConverter/releases/latest) 下載 `WinMdConverter-Setup-版本-x64.exe`。
2. 執行安裝程式。
3. 選擇是否建立桌面捷徑。
4. 若需要在 PowerShell 或命令提示字元直接使用 `mdconvert`，勾選「將 mdconvert CLI 加入使用者 PATH」。
5. 完成後從開始功能表啟動 WinMdConverter。

安裝檔目前未進行程式碼簽章，因此 Windows SmartScreen 可能顯示「Windows 已保護您的電腦」。請確認檔案來自本專案 GitHub Release 後，再選擇「其他資訊」及「仍要執行」。

### 可攜版

1. 下載 `WinMdConverter-版本-win-x64.zip`。
2. 將 ZIP 完整解壓縮至可寫入的資料夾。
3. 執行 `WinMdConverter.exe`。
4. CLI 可使用同一資料夾內的 `mdconvert.exe`。

請勿只複製其中一個 EXE。可攜版為 self-contained 多檔發佈，執行時需要同一資料夾內的 DLL 與 Runtime 檔案。

## 圖形介面

### 選擇來源

按下「選擇檔案」，選取一個 `.md` 或 `.markdown` 文件。第一版一次只轉換一個文件。

### 設定輸出

- 輸出資料夾預設使用來源文件所在位置，也可以自行指定。
- 可勾選 HTML、PDF 或同時勾選兩者。
- 若目標檔案已存在，軟體會在轉換前詢問是否覆寫。

### 選擇字型

字型清單來自目前 Windows 已安裝的字型。所選字型會套用至正文、標題、表格及目錄；程式碼區塊維持等寬字型。

HTML 移到其他電腦後，如果該電腦沒有相同字型，瀏覽器會使用備用字型。PDF 會依產生端的字型完成排版。

### 紙張方向

- 直向：A4 210 × 297 mm。
- 橫向：A4 297 × 210 mm。

紙張設定主要套用於 PDF 及 HTML 的列印樣式，不限制 HTML 在螢幕上的閱讀寬度。

### 縮放比例

- 符合可列印區域：限制圖片、表格、程式碼及長網址寬度，避免水平內容被裁切。
- 自訂：可輸入 50%～200%。

### 邊界

| 模式 | 上、右、下、左 |
|---|---|
| 預設 | 20 mm |
| 無 | 0 mm |
| 最小值 | 5 mm |
| 自訂 | 每邊可輸入 0～50 mm |

無邊界 PDF 的頁面邊界為 0，但實際印表機仍可能受到硬體不可列印區域限制。

### 文件目錄

勾選「在文件開頭顯示目錄」後，軟體會根據 H1～H6 標題建立階層式目錄。HTML 與支援內部連結的 PDF 閱讀器可點擊跳轉。

### 轉換與取消

按下「開始轉換」後，介面會顯示目前階段及百分比。此時「結束」按鈕會改為「取消」。取消後會停止轉換並清除尚未完成的暫存檔案。

系統未執行轉換時，按下「結束」會關閉視窗。

### 完成結果

成功後可直接選擇：

- 開啟 HTML
- 開啟 PDF
- 開啟輸出資料夾

若其中一種格式失敗，畫面會顯示「部分轉換完成」，並保留成功輸出的連結。

## 圖片處理

- 本機相對圖片路徑以 Markdown 文件所在資料夾為基準。
- 支援 PNG、JPEG、GIF、WebP、BMP 及 SVG。
- 本機圖片會轉為 Data URI 並內嵌至 HTML，方便移動單一 HTML 文件。
- 遠端 HTTP/HTTPS 圖片保留原始網址，離線時可能無法顯示。
- 找不到圖片時會顯示警告，其餘內容仍可輸出。

## 常見問題

### HTML 可以輸出，但 PDF 失敗

PDF 使用系統 Microsoft Edge Headless 產生。請確認 Microsoft Edge 已安裝且可正常啟動。

### 選定字型後，另一台電腦的 HTML 外觀不同

HTML 不會內嵌 Windows 字型。另一台電腦若未安裝相同字型，就會使用 CSS 備用字型。需要固定外觀時請使用 PDF。

### SmartScreen 顯示警告

目前 `v0.1.0` 未使用程式碼簽章。請只從本專案 GitHub Release 下載，並可比對 Release 提供的 SHA-256 摘要。

### 輸出檔案被占用

關閉正在開啟該 HTML 或 PDF 的程式，再重新轉換；或改用其他輸出資料夾。
